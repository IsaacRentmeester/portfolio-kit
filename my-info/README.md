# my-info: your private inputs

Drop these files here. Nothing in this folder is published or committed (see `.gitignore`).

| File | How to get it |
|---|---|
| `resume.pdf` (or .docx) | Your current résumé. |
| `linkedin.pdf` | On LinkedIn (desktop): your profile → **More** (or **Resources**) → **Save to PDF**. |
| `photos/` | A headshot (square, face centered) plus up to 3 photos of you doing things you care about. |
| `notes.md` (optional) | Anything not on your résumé: what you're proud of, what you want next, hobbies, hometown. |

Claude reads these, then writes the public versions into `content/`, `photos/` and `files/`.
The public résumé copy in `files/` should have **no phone number and no home address**.
